# ADR-0006: Backend stack — Python/FastAPI replaces Spring Boot

- **Status:** Accepted (2026-11-09) — supersedes ADR-0001 (backend portion)
- **Context:** ADR-0001 placed the API/search layer on Java 21/Spring Boot and the adapters on Python, accepting a cross-language boundary. By the end of M9 the entire backend surface is stable (REST + MCP over PostgreSQL/OpenSearch) and the two-language split now costs more than it buys: every contract change is edited twice, and the edit→verify loop for the Java backend is ~20 s (compile 9 s + package 4 s + boot 6 s) even with a warm Maven cache, while the matching/adapters ecosystem the team actually extends is Python. M10 (`docs/milestones/m10-fastapi-migration-task.md`) approved migrating the backend to Python/FastAPI with full regression parity.
- **Decision:** The backend is a FastAPI + Pydantic application run under `uv` (`uv sync --locked`, `uv run uvicorn app.main:create_app --factory`, `uv run pytest -q`). Domain logic stays separated from HTTP routes and persistence (`app/services`, `app/routes`, `app/repositories`); money/quantity math uses `decimal.Decimal`. PostgreSQL (authoritative), OpenSearch 3.x projections, migrations V1..V5, adapter workers, scheduler and Docker Compose infra are unchanged from ADR-0001/0002. Jackson wire compatibility is preserved: camelCase payloads, ISO instants, decimals as JSON numbers, Spring-shaped error bodies (`{timestamp, status, error, path}`), and the MCP `2024-11-05` JSON-RPC surface — enforced by a differential harness (`scripts/test-m10-diff.ps1` + `backend_py/tools/diff_harness.py`, 48 request pairs on identical data clones) plus the ported unit suite.
- **Alternatives considered:** Keeping Spring Boot (rejected: double maintenance, slow loop, duplicate contracts); rewriting incrementally endpoint-by-endpoint behind a proxy (rejected: more moving parts than the single-swap differential approach for a backend this small).
- **Measurements (2026-11-09, same host):** backend test suite `mvn -B test` 9.0 s → `uv run pytest -q` 10.3 s; build/package 3.9 s → `uv sync --locked` 0.6 s (source-mounted, no artifact); cold boot → health UP 6.19 s → 1.5 s; targeted test file ~10 s → 0.7 s; edit→verify loop ~20 s → ~1 s (plus sub-second uvicorn `--reload`).
- **Consequences:** One language across backend, adapters and matching — contracts live next to their tests. CI runs the FastAPI suite and keeps the differential Java-vs-FastAPI gate until owner sign-off; the Java tree (`backend/`) is retained untouched for instant rollback (re-point CI steps at `mvn`), and its removal is a follow-up commit after M10 review. `--factory` app mode is required by uvicorn (no module-level app object).
